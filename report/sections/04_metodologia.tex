\subsection{Pipeline}
El flujo completo, reproducible de punta a punta, es:
\[
\texttt{data/raw/} \xrightarrow{\text{Bloque B}} \texttt{base\_limpia.parquet} \xrightarrow{\text{Bloque D}} X_{\text{train}}, X_{\text{val}}, X_{\text{test}} \xrightarrow{\text{Bloque E}} \texttt{letalidad\_nn.keras} \xrightarrow{\text{Bloque F}} \text{eval. en test} \xrightarrow{\text{Bloque G}} \texttt{streamlit\_app.py}
\]

\subsection{Herramientas y versiones}
\begin{itemize}
  \item Python 3.12.13 en macOS (ARM); idéntica versión en Windows.
  \item TensorFlow $\geq$ 2.18, ``\textless 2.20'' (con Keras 3 integrado, formato \texttt{.keras}).
  \item scikit-learn $\geq$ 1.6 (líneas base, métricas, \texttt{StandardScaler}, \texttt{compute\_class\_weight}).
  \item imbalanced-learn $\geq$ 0.13 (SMOTE, solo si aplica C4).
  \item shap $\geq$ 0.46, interpretabilidad.
  \item pandas $\geq$ 2.2, numpy $\geq$ 2.0, pyarrow, matplotlib $\geq$ 3.9, seaborn $\geq$ 0.13, plotly $\geq$ 5.24.
  \item streamlit $\geq$ 1.40, interfaz gráfica web local.
  \item holidays, feriados del Perú; joblib, persistencia.
\end{itemize}
Los congelados exactos por plataforma se incluyen en los anexos A6 y A7.

\subsection{Semillas y reproducibilidad}
Al inicio de todo notebook y script se fijaron las semillas:
\begin{lstlisting}
import os, random, numpy as np, tensorflow as tf
SEED = 42
os.environ["PYTHONHASHSEED"] = str(SEED)
random.seed(SEED); np.random.seed(SEED); tf.random.set_seed(SEED)
\end{lstlisting}
El modelo canónico se entrenó una sola vez en la máquina macOS del integrante Rendo. Los artefactos \texttt{letalidad\_nn.keras}, \texttt{scaler.pkl}, \texttt{encoders.pkl}, \texttt{feature\_list.json} y \texttt{threshold.json} se versionaron en Git y los consumió el otro integrante, sin re-entrenar. Las cifras de este informe provienen exclusivamente de ese artefacto.

\subsection{Separación de subconjuntos}
Para no confundir ``probar la interfaz'' con ``evaluar el modelo'', se manejaron cuatro conceptos distintos: entrenamiento (ajustar pesos y \emph{fits}), validación (elegir hiperparámetros, \emph{early stopping} y calibrar el umbral), prueba final (evaluación única e intocable) y casos de demostración (probar la inferencia de la interfaz, jamás medir desempeño). Los casos de demostración se construyeron desde validación y casos sintéticos controlados, nunca desde la prueba final.
