\subsection{Diseño experimental definitivo}
El proyecto sigue CRISP-DM con una separación cronológica estricta. Este corte es el mecanismo definitivo para medir deriva entre periodos y bloquear el uso de información futura.

\subsection{Flujo reproducible}
\begin{align*}
\texttt{base\_limpia.parquet}
&\xrightarrow{\text{corte cronológico}} \{2021\text{--}22,\ 2023,\ 2024\text{--}25\}\\
&\xrightarrow{\text{fit solo 2021--22}} \text{162 features procesadas}\\
&\xrightarrow{\text{selección 2023}} \texttt{MLP\_64\_32, seed 314, t=0.65}\\
&\xrightarrow{\text{5-fold OOF 2023}} \text{Platt + umbral calibrado 0.20}\\
&\xrightarrow{\text{congelar}} \texttt{models/final/}\\
&\xrightarrow{\text{referencia 2024--25}} \text{métricas, IC y errores}.
\end{align*}

\subsection{Selección del modelo}
Se compararon tres configuraciones MLP y tres semillas (42, 314 y 2718). La configuración se eligió por mediana de PR-AUC en validación, luego mediana de F1 y finalmente menor rango intercuartílico de PR-AUC. La semilla 314 quedó asociada al artefacto seleccionado. Los mismos datos y la misma política de umbral se aplicaron a regresión logística balanceada y Random Forest balanceado para evitar comparaciones ventajosas.

\subsection{Calibración y umbrales}
Platt e isotónica se compararon mediante Brier OOF de cinco particiones estratificadas dentro de 2023~\cite{scikit_learn_2024}. Se seleccionó Platt por menor Brier OOF; el umbral calibrado 0.20 maximizó F1 sobre esas probabilidades OOF. El umbral crudo 0.65 proviene de la política predeclarada sobre scores de validación. Las escalas no se mezclan y la interfaz toma decisiones visibles solo en la escala calibrada.

\subsection{Evaluación e incertidumbre}
Se reportan dos vistas del mismo modelo congelado: score crudo y probabilidad Platt. Para las métricas de referencia se calcularon 1\,000 remuestreos bootstrap al 95\,\%. La evaluación incluye comparación con prevalencia, regresión logística y Random Forest; no se realizan pruebas o ajustes posteriores que reclasifiquen 2024--2025 como un nuevo periodo no observado.

\subsection{Explicabilidad separada de la referencia}
Gradient SHAP se ejecutó sin cargar etiquetas ni datos de 2024--2025~\cite{lundberg_shap_2017}. El fondo procede de entrenamiento y la muestra explicada de validación. Esta separación evita que la interpretación se convierta en una vía indirecta de ajuste a la referencia.

\subsection{Implementación}
La implementación usa Python 3.12, TensorFlow 2.19, scikit-learn 1.9, pandas 3.0, NumPy 2.1, SHAP 0.52, Streamlit y Plotly~\cite{tensorflow_2024,keras_2024,scikit_learn_2024}. \path{models/final/manifest.json} fija versiones, hashes, particiones, arquitectura, calibrador y umbrales; el cargador de inferencia rechaza artefactos alterados.
