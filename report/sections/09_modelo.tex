\section{Modelo neuronal}\label{sec:modelo}

\subsection{Búsqueda cerrada y reproducible}
Se definieron tres configuraciones completas y tres semillas antes de consultar el periodo de referencia 2024--2025. Cada configuración varía conjuntamente capas, \emph{dropout}, L2 y tasa de aprendizaje. Cada corrida usó el mismo entrenamiento 2021--2022 y validación 2023, con entropía cruzada binaria, pesos de clase, Adam, reducción de tasa de aprendizaje y parada temprana por PR-AUC. La configuración se eligió por mediana de PR-AUC entre semillas; F1 mediana y menor dispersión actuaron como desempates. La misma búsqueda se ejecutó íntegra para la versión 2 con las 175 características.

\subsection{Arquitectura congelada}
La MLP canónica es \texttt{MLP\_32\_16} con semilla 314: entrada de 175 variables, capas densas de 32 y 16 neuronas con ReLU, \emph{dropout} 0.25, L2 de $1\times10^{-4}$, Adam con $1\times10^{-3}$ y lote 64. El modelo final conserva exactamente el hash del artefacto seleccionado; materializar \path{models/final/} no reentrena ni vuelve a buscar pesos.

\subsection{Comparadores y política de umbral}
El clasificador constante por prevalencia, la regresión logística balanceada y el Random Forest balanceado se entrenaron con las mismas particiones; los dos modelos aprendidos recibieron las mismas 175 variables. Para cada modelo, el umbral se escogió solo en validación con la misma regla: máximo F1; empates por \emph{recall}, precisión y mayor umbral. Para la MLP cruda se obtuvo 0.80.

\subsection{Calibración Platt OOF}
Sobre los scores de validación 2023 se generaron predicciones OOF con cinco particiones estratificadas. En esa selección, Platt obtuvo Brier OOF 0.0652 (ECE 0.0086) y quedó seleccionado frente a la isotónica. El umbral calibrado 0.30 se eligió sobre probabilidades OOF calibradas. Estos valores pertenecen exclusivamente a validación; el Brier 0.0683 informado en resultados corresponde a la referencia histórica 2024--2025 después de ajustar Platt con toda la validación. El procedimiento separa selección y referencia, y evita usar las etiquetas 2024--2025 para elegir el calibrador~\cite{scikit_learn_2024}.
