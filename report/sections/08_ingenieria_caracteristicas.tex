\section{Ingeniería de características}\label{sec:ingenieria}

Se construyeron 72 características finales a partir de las seis variables base. Cada una justificada por una señal observada en el análisis exploratorio o por una razón técnica de las redes neuronales. La \autoref{tab:features-principales} muestra las derivadas más relevantes (el listado completo de las 72 está en el Anexo y en \texttt{tab02\_feature\_contract.csv}).

\subsection{Características temporales (de \texttt{FECHA})}
\begin{itemize}
  \item \texttt{anio}: menos útil para modelos, se conserva por completitud.
  \item \texttt{mes} (1--12): estacionalidad.
  \item \texttt{dia\_semana} (0--6) y \texttt{fin\_de\_semana} (booleano): patrones por día de semana (H4).
  \item \texttt{feriado} (booleano, usando \texttt{holidays.country\_holidays("PE")}).
  \item \texttt{quincena} (booleano, días 14--16 y 29--2): \emph{proxy} de pago y viajes, justificado en el informe como señal socioeconómica conocida en Perú.
\end{itemize}

\subsection{Características horarias (de \texttt{hora\_entera})}
\begin{itemize}
  \item \textbf{Codificación cífácil:} \texttt{hora\_sin = sin(2$\pi$ h/24)} y \texttt{hora\_cos = cos(2$\pi$ h/24)}. La razón técnica es que para la red, 23 y 0 deben ser vecinos; con la hora cruda distan 23 unidades, lo que rompe la continuidad cíclica del día.
  \item \texttt{nocturno} (booleano, 20:00--05:59): nocturnidad y fatiga.
  \item \texttt{franja} (MADRUGADA 0--5, MAÑANA 6--11, TARDE 12--17, NOCHE 18--23): agrupa periodos interpretables.
  \item Filas con \texttt{hora\_entera} nula: \texttt{hora\_sin = hora\_cos = 0} + \texttt{hora\_faltante = 1}.
\end{itemize}

\subsection{Características geográficas}
\begin{itemize}
  \item \emph{One-Hot} de \texttt{DEPARTAMENTO} (25 columnas).
  \item \texttt{region\_natural} (COSTA / SIERRA / SELVA / DESCONOCIDO): mapeo fijo departamento $\rightarrow$ región, escrito explícitamente en \texttt{src/features.py}. Agrupa patrones geográficos generales para reducir dispersión.
\end{itemize}

\subsection{Características de vía (contingencia C11)}
\begin{itemize}
  \item \texttt{via\_prefijo}: parte alfabética del código (p.\,ej.\ \texttt{PE}, \texttt{LM}, \texttt{IC}) $\rightarrow$ \emph{One-Hot}. Representa familias de vías sin depender del código completo.
  \item \texttt{via\_freq}: frecuencia relativa del código completo, calculada solo en \emph{train}. Códigos no vistos en \emph{val} o \emph{test} se mapean a 0, evitando fuga y manejando categoría no vista.
\end{itemize}
No se aplicó \emph{One-Hot} masivo sobre el código completo (la cardinalidad es alta y el \emph{One-Hot} generaría miles de columnas sin generalización): se usó \emph{frequency encoding} en su lugar, decisión que figura en el listado de errores prohibidos del Plan.

\subsection{Característica numérica de kilómetro}
\texttt{KILOMETRO} se imputa con la mediana de \emph{train} y se le añade el \emph{flag} \texttt{km\_faltante}; posteriormente se escala. La distribución observada en la figura~\ref{fig:fig11} (concentración por tramos) justifica conservarla como variable numérica.

\subsection{Característica de modalidad}
\texttt{MODALIDAD} se imputa a \texttt{DESCONOCIDO} y se codifica con \emph{One-Hot} de seis categorías cerradas: ATROPELLO, CHOQUE, DESPISTE, ESPECIAL, VOLCADURA, DESCONOCIDO. La mecánica del accidente impacta directamente la severidad (figura~\ref{fig:fig07}, H5).
