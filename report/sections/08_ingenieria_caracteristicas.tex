\section{Ingeniería de características}\label{sec:ingenieria}

Se construyeron 116 características finales a partir de las variables pre-impacto del registro. Cada una justificada por una señal observada en el análisis exploratorio o por una razón técnica de las redes neuronales. La \autoref{tab:features-principales} muestra las derivadas más relevantes (el listado completo está en el Anexo y en \texttt{tab02\_feature\_contract.csv}).

\subsection{Características temporales (de \texttt{FECHA})}
\begin{itemize}
  \item \texttt{anio}: captura la deriva del registro 2021--2025; se escala como continua.
  \item \texttt{mes} (1--12): estacionalidad.
  \item \texttt{dia\_semana} (0--6) y \texttt{fin\_de\_semana} (booleano): patrones por día de semana (H4).
  \item \texttt{feriado} (booleano, usando \texttt{holidays.country\_holidays("PE")}).
  \item \texttt{quincena} (booleano, días 14--16 y 29--2): \emph{proxy} de pago y viajes.
\end{itemize}

\subsection{Características horarias (de \texttt{hora\_entera})}
\begin{itemize}
  \item \textbf{Codificación cíclica:} \texttt{hora\_sin = sin(2$\pi$ h/24)} y \texttt{hora\_cos = cos(2$\pi$ h/24)}. Para la red, 23 y 0 deben ser vecinos; con la hora cruda distan 23 unidades, lo que rompe la continuidad cíclica del día.
  \item \texttt{nocturno} (booleano, 20:00--05:59): nocturnidad y fatiga.
  \item \texttt{franja} (MADRUGADA 0--5, MAÑANA 6--11, TARDE 12--17, NOCHE 18--23).
  \item Filas con \texttt{hora\_entera} nula: \texttt{hora\_sin = hora\_cos = 0} + \texttt{hora\_faltante = 1}.
\end{itemize}

\subsection{Características geográficas}
\begin{itemize}
  \item \emph{One-Hot} de \texttt{DEPARTAMENTO} (25 columnas).
  \item \texttt{region\_natural} (COSTA / SIERRA / SELVA / DESCONOCIDO): mapeo fijo departamento $\rightarrow$ región, escrito explícitamente en \texttt{src/features.py}.
  \item \texttt{LATITUD} y \texttt{LONGITUD}: señal espacial continua estandarizada, con imputación por mediana de \emph{train} y \emph{flag} \texttt{coord\_faltante}. Es la primera vez que el proyecto dispone de geolocalización exacta (H11).
\end{itemize}

\subsection{Características de vía}
\begin{itemize}
  \item \texttt{via\_prefijo}: parte alfabética del código de carretera (p.\,ej.\ \texttt{PE}, \texttt{LM}, \texttt{CU}) $\rightarrow$ \emph{One-Hot}. Representa familias de vías.
  \item \texttt{via\_freq}: frecuencia relativa del código completo, calculada solo en \emph{train}; códigos no vistos se mapean a 0.
  \item \texttt{red\_vial\_*}: NACIONAL / DEPARTAMENTAL / PROVINCIAL / URBANO / DESCONOCIDO.
  \item \texttt{tipo\_via\_*}: CARRETERA / AVENIDA / CALLE / EXPRESA / OTRO / DESCONOCIDO (agrupa calle, jirón, pasaje y alameda en CALLE; vía expresa y autopista en EXPRESA).
\end{itemize}

\subsection{Características de condiciones pre-impacto (nuevas en esta fuente)}
Estas variables son el aporte central del cambio de dataset (H8):
\begin{itemize}
  \item \texttt{zona\_*}: RURAL / URBANA / DESCONOCIDO. La ruralidad cuadruplica la tasa multifatal.
  \item \texttt{clima\_*}: DESPEJADO / NUBLADO / LLUVIOSO / NIEBLA / OTRO / DESCONOCIDO (agrupa soleado en despejado; granizo y nieve en lluvioso).
  \item \texttt{caracteristica\_*}: RECTO / CURVA / INTERSECCION / ESTRUCTURA / OTRO / DESCONOCIDO (agrupa sinuosa en curva; óvalo en intersección; puente, túnel y pase a desnivel en estructura).
  \item \texttt{perfil\_*}: PLANA / INCLINADA / DESCONOCIDO.
  \item \texttt{superficie\_*}: PAVIMENTADA / AFIRMADO / TROCHA / DESCONOCIDO (agrupa asfaltada, concreto, adoquinado y empedrado en pavimentada; cascajo/ripio en trocha).
\end{itemize}

\subsection{Característica de clase de siniestro}
\texttt{CLASE} se normaliza a seis categorías cerradas: ATROPELLO (incluye atropello con fuga), CHOQUE (incluye choque con fuga y con objeto fijo), DESPISTE (incluye despiste y volcadura combinados), VOLCADURA, ESPECIAL (caída de pasajero, ferroviario, incendio) y DESCONOCIDO. La mecánica del evento impacta directamente la letalidad (figura~\ref{fig:fig07}, H5).
