\subsection{Anexo A1: Diccionario de datos completo}
La base ONSV incluye sus encabezados descriptivos en la propia hoja \texttt{SINIESTROS}. El mapeo completo de columnas originales a nombres canónicos (p.\,ej.\ \texttt{FECHA SINIESTRO} $\rightarrow$ \texttt{FECHA}, \texttt{COD CARRETERA} $\rightarrow$ \texttt{CODIGO\_VIA}, \texttt{CANTIDAD DE FALLECIDOS} $\rightarrow$ \texttt{FALLECIDOS}) está declarado en \texttt{COLUMN\_MAP} dentro de \texttt{src/block\_b\_dataset\_audit.py}. Se conservan en \texttt{data/raw/} los archivos de la primera iteración (CSV Sutran y su diccionario) como evidencia histórica.

\subsection{Anexo A7: Enlace al repositorio y reproducibilidad}
El repositorio contiene comandos exactos para reproducir el pipeline, lanzar la GUI y compilar el informe:

\begin{lstlisting}[language=bash]
# Entorno
python3.12 -m venv .venv && source .venv/bin/activate  # macOS
pip install -r requirements.txt

# Pipeline (scripts por bloque, en orden)
python src/block_b_dataset_audit.py
python src/block_c_eda.py
python src/block_d_preprocessing.py
python src/block_e_modeling.py
python src/block_f_evaluation.py
python src/block_f_posthoc_calibration.py
python src/block_g_app_check.py
python tests/test_preprocessing_contract.py

# Interfaz
streamlit run app/streamlit_app.py

# Informe
cd report && latexmk -pdf -interaction=nonstopmode main.tex
# el PDF final se copia a report/output/informe.pdf
\end{lstlisting}

Los congelados por plataforma (\texttt{requirements-macos.txt}, \texttt{requirements-windows.txt}) registran las versiones exactas usadas por cada integrante como evidencia de reproducibilidad.
