\subsection{Anexo A7: Enlace al repositorio y reproducibilidad}
El repositorio contiene comandos exactos para reproducir el pipeline, lanzar la GUI y compilar el informe:

\begin{lstlisting}[language=bash]
# Entorno
python3.12 -m venv .venv && source .venv/bin/activate  # macOS
pip install -r requirements.txt

# Pipeline (notebooks en orden)
jupyter notebook notebooks/00_auditoria_dataset.ipynb
jupyter notebook notebooks/01_eda.ipynb
jupyter notebook notebooks/02_prep_features.ipynb
jupyter notebook notebooks/03_model.ipynb
jupyter notebook notebooks/04_evaluacion_final.ipynb

# Interfaz
streamlit run app/streamlit_app.py

# Informe
cd report && latexmk -pdf -interaction=nonstopmode main.tex
# el PDF final se copia a report/output/informe.pdf
\end{lstlisting}

Los congelados por plataforma (\texttt{requirements-macos.txt}, \texttt{requirements-windows.txt}) registran las versiones exactas usadas por cada integrante como evidencia de reproducibilidad.
