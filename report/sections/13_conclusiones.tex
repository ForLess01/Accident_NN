\section{Conclusiones}\label{sec:conclusiones}

\begin{itemize}
\item Se construyó una única MLP 169--64--32--1 con 12\,993 parámetros y técnicas de regularización realmente ejecutadas.
\item La arquitectura se seleccionó con 2021/2022, se reajustó en 2021--2022 y se calibró en 2023; dos folds rolling verifican roles cronológicos disjuntos dentro de cada diagnóstico.
\item La prueba ejecutable confirmó que PERSONAS reconstruye el objetivo para los 9\,104 registros; excluir esa familia fue obligatorio.
\item En la referencia 2024--2025 ya consultada, PR-AUC es 0.3254, ROC-AUC 0.7916 y F1 calibrado 0.3989. El desempeño es moderado y se reporta sin sobreestimación.
\item La interfaz muestra cinco roles pedagógicos, separa verdad observada de estimación, valida paridad y no ofrece intervalos individuales inexistentes.
\item El bundle, las fuentes, las demos, la explicabilidad y el PDF están sellados por contenido.
\end{itemize}

El artefacto entregado es reproducible y está verificado por contenido. No constituye una validación confirmatoria externa: el proyecto no dispone de una cohorte prospectiva o externa intacta. Esa distinción entre finalización del artefacto e independencia científica es una conclusión, no una nota al pie.
