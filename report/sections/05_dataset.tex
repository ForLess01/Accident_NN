\section{Dataset}\label{sec:dataset}

\subsection{Fuente oficial}
Se utilizó el conjunto \emph{Accidentes de tránsito en carreteras 2020--2021 -- Sutran}, publicado por la PNP y la CGM/Sutran en la Plataforma Nacional de Datos Abiertos del Perú. El recurso exacto usado por el equipo está disponible en:

\begin{quote}
\url{https://www.datosabiertos.gob.pe/dataset/accidentes-de-tr\%C3\%A1nsito-en-carreteras/resource/3398beff-8440-4343-a54d-0911d11dfcd5}
\end{quote}

\noindent El archivo original (\texttt{Accidentes de tránsito en carreteras-2020-2021-Sutran.csv}) y el diccionario de datos (\texttt{Formato\_2\_Diccionario\_de\_datos.docx}) se mantienen en \texttt{data/raw/} con sus nombres originales. La fecha de descarga y verificación local fue el 2026-07-08. Es un dato abierto bajo licencia de datos abiertos del Estado peruano, lo que permite libre reuso con atribución.

\subsection{Variable objetivo}
Se construyó el target binario:
\[
y = 1 \iff \texttt{FALLECIDOS} > 0 \quad \text{(``MORTAL'')}, \qquad y = 0 \text{ en caso contrario (``NO MORTAL'')}
\]
Las filas con \texttt{FALLECIDOS} nulo (los casos ``N.I.'' del diccionario) se eliminaron: no se imputa un \emph{target}. La prohibición de \texttt{FALLECIDOS} y \texttt{HERIDOS} como entradas se declara explícitamente como decisión metodológica en la \autoref{sec:preprocesamiento} para evidenciar la guarda anti-fuga.

\subsection{Auditoría inicial}
La auditoría (Bloque B) verificó y registró:
\begin{itemize}
  \item Separador real: punto y coma (\texttt{;}).
  \item Encoding funcional: \texttt{latin-1}.
  \item Número de filas original: 8\,155.
  \item Duplicados exactos eliminados: 35.
  \item Filas con target nulo eliminadas: 3.
  \item N final útil: 8\,117.
  \item Casos mortales: 951 (11.72\,\%).
  \item Rango temporal: 2020 a 2021.
\end{itemize}

Como $3\,000 \leq N < 10\,000$ se aplicó la contingencia C2 (arquitectura A, \emph{split} 70/15/15). Como el porcentaje de clase mortal se ubica entre 5\,\% y 25\,\%, se aplicó C5: \texttt{class\_weight} sin SMOTE. El formato real de \texttt{HORA} fue texto \texttt{HH:MM}, por lo que se aplicó el parser C7. \autoref{tab:audit} resume la auditoría.
